Phonics Practice - 部署到 GitHub Pages
1. 在 GitHub 新建仓库（Public），例如 phonics
2. 点 "uploading an existing file"，把本文件夹里的所有文件（含 icons 文件夹）拖进去，Commit
3. 仓库 Settings -> Pages -> Source 选 "Deploy from a branch"，Branch 选 main，文件夹 / (root)，Save
4. 1-2 分钟后访问 https://你的用户名.github.io/phonics/
5. iPad Safari 打开该网址 -> 分享 -> 添加到主屏幕
